# Galung.id — API Engineering Package v1.0

**Source of truth:** `openapi.yaml`; equivalent `openapi.json`.

## Files

1. `openapi.yaml` — OpenAPI 3.1.0 Phase 00 review draft, 69 operations, 44 reusable schemas, 65 paths.
2. `openapi.json` — machine-readable JSON export of identical contract.
3. `API_SPECIFICATION.md` — architecture, conventions, state machines, errors, examples.
4. `DESKTOP_LICENSING_API_NOTES.md` — licensing flow, signed claims and security invariants.
5. `SCHEMA_ALIGNMENT_NOTES.md` — DB vs API design gaps; P0 resolution required.
6. `API_TEST_MATRIX.md` — verification cases, contract/integration/security gates.

**Important:** This is a draft contract for implementation planning, not a deployed service. The Phase 00 additions are generated by `build_api.py` from this repository path; SQL companions `database/003_phase00_contract_delta.sql` and `database/004_fixed_subscription_terms.sql` is also a review draft. Some policy and provider decisions remain open; see the Phase 00 owner decision log and cross-functional review. Draft API 1.1.0-draft.2 uses `termDays` 30/365. The draft is limited to Basic/Pro MVP, manual bank transfer, international customers, 14-day max offline, 72h grace and manual license issuance.

Suggested repository location: `documentation/api/`; copy `openapi.yaml` into `apps/api/openapi/` after team review. Generate typed clients only after resolving open design questions. `build_api.py` is the local deterministic generator of the OpenAPI artifacts.
