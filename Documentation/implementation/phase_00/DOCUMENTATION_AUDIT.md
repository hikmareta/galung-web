## UI and accessibility extraction

28 named screens across public, auth, checkout, My Galung and admin. Core flow separates proof, verified funds, and license issue. All asynchronous components require loading/empty/error/forbidden/conflict states; money shows ISO currency, temporal events show timezone. Target WCAG 2.2 AA, keyboard/focus, caption/transcript, reduced motion, 320px mobile. Design tokens are proposals pending official branding and contrast checks. Form requirements include verified email, server quote, international remittance data, private JPG/PNG/PDF proof, admin credit details, immutable policy version, and MFA for sensitive bank edits. See UI §§1–8, design §§1–4, UX matrix A–D.
